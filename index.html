Safety & notes

Antivirus / SmartScreen

Recommended: install from the Microsoft Store — Windows trusts Store apps and you get automatic updates.

The direct zip from this site is also safe freeware. Some PCs show SmartScreen or antivirus warnings on unsigned indie EXEs (false positive). Only install from official links. If Windows blocks the zip build: More info → Run anyway.

Important notes

  • SID/STAR tracks are approximate for sim use (not official AIP plates).
  • Surface data quality depends on OpenStreetMap coverage at each airport.
  • Live aircraft requires MSFS and NavApron on the same PC, with a flight loaded.
  • SimBrief OFP generation happens on SimBrief’s site; NavApron imports the result.
