How it works

Three steps from download to taxi clearance.

01

Download & launch

Grab the free Windows app from flightsim.to. No installer drama — just run it alongside MSFS.

02

Search your airport

Type the ICAO or name. The interactive chart appears with taxiways, runways, aprons and gates ready to explore.

03

Build route & fly

Use the clearance builder or pathfinding. Your aircraft shows live on the map via SimConnect. Follow mode keeps you centred.

Safety & notes

Antivirus / SmartScreen

NavApron is free sim software and is safe to run. Some PCs show Windows SmartScreen or antivirus warnings. This is a false positive, not a virus. Only install from the official download.

If Windows blocks it: More info → Run anyway. Optional: add an exclusion for the NavApron folder after you verify the source.

Important notes

  • SID/STAR tracks are approximate for sim use (not official AIP plates).
  • Surface data quality depends on OpenStreetMap coverage at each airport.
  • Live aircraft requires MSFS and NavApron on the same PC, with a flight loaded.
