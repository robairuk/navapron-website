        SID / departure route

        Uses the departure runway you already picked above — no need to choose it again. SID = path from runway to enroute. Catalog SIDs load when available; otherwise vector suggestions fill the list automatically.

        Departure runway

        Same runway as Taxi — change either list and both stay in sync. SID tools appear below.

        Arrival runway

        STAR draws green; taxi-in (runway → gate) draws cyan on the same chart.

        Taxi-in (after landing → gate)

        Tries early exits along the runway plus full length, then picks the best path to your stand. Live aircraft is preferred when connected. Tap taxiway buttons or click yellow taxiways on the map (same as outbound).

        Load destination airport / switch to Arrival — taxiways appear here.

        STAR / arrival route

        STAR = Standard Terminal Arrival (path from enroute into the approach). Published STARs appear after you pick a runway; if none are in the catalog, vector suggestions fill the list automatically. Suggest refreshes them. Same idea for SIDs on departure (path from runway to enroute).

        Gate-to-gate flight

        Plan enroute, then load both airports so taxi-out and taxi-in charts stay on the map. If you already drew a SID and/or STAR, the plan joins the SID exit to the first fix and the last fix to the STAR entry (updates when you change SID/STAR).

        SimBrief

        Enter your free SimBrief username, set dep/dest above, then Generate & import. SimBrief opens prefilled — click Generate Flight Plan there; NavApron waits and imports the new OFP automatically (no manual re-import).
